# App Permissions & Device Access Control

## 1. What I Learned
App permissions define what installed applications are allowed to access on a device, such as camera, microphone, location, files, contacts, or background activity.

Good device security follows the principle of least privilege, meaning apps should only get the minimum access they actually need.

## 2. Why It Matters
Unnecessary permissions increase privacy and security risk. Even if an app is not obviously malicious, excessive access can expose sensitive data, tracking behavior, or weaken device control.

Permission hygiene is an important part of overall device security.

## 3. Practical Exploration
I reviewed permissions for multiple installed apps and checked whether the requested access actually matched the app’s purpose.

I also removed unnecessary permissions and identified apps that may have been over-trusted.

## 4. Key Takeaway
- Permissions are trust decisions
- Apps should only get minimum required access
- Reviewing old permissions is part of good security hygiene

## 5. Tools / Concepts Used
- Permission audit
- Principle of least privilege
- Device privacy settings
- Access control awareness
