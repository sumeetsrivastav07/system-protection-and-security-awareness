# Browser Safety & Risky Web Habits

## 1. What I Learned
A browser is one of the most exposed parts of a personal device because it handles websites, downloads, sessions, extensions, saved logins, and account access.

Browser safety is about reducing exposure to scams, fake pages, risky downloads, unsafe extensions, and careless browsing habits.

## 2. Why It Matters
Many real-world security issues begin inside the browser through phishing pages, suspicious downloads, unsafe links, and over-trusted browser behavior.

Good browser hygiene improves both personal security and technical awareness.

## 3. Practical Exploration
I reviewed my browser environment by checking:

- installed extensions
- login/session habits
- notification permissions
- download behavior
- overall browsing trust decisions

I also removed or reviewed unnecessary browser risks.

## 4. Key Takeaway
- Browsers are high-risk trust environments
- “Looks legit” is not a real security check
- Extensions, downloads, and login habits should be treated carefully

## 5. Tools / Concepts Used
- Browser extension audit
- Download hygiene
- Session awareness
- Web trust evaluation
