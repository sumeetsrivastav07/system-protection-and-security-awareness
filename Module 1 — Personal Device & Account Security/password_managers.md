# Password Managers

## 1. What I Learned
A password manager is a tool that helps securely store, generate, and manage passwords. It reduces password reuse and makes it practical to maintain strong unique credentials across many accounts.

Good password managers rely on encrypted vaults and are protected by a master password.

## 2. Why It Matters
Managing many accounts manually often leads to weak or reused passwords. A password manager helps reduce human error and supports better password hygiene at scale.

This improves both personal account safety and technical security awareness.

## 3. Practical Exploration
I evaluated what a good password manager should provide, including:

- strong password generation
- autofill support
- vault locking
- secure storage
- reduced password reuse

I also reviewed saved browser passwords to observe weak, reused, or outdated credentials.

## 4. Key Takeaway
- Password managers solve a real human security problem
- They are useful only when used properly
- The master password is critical and must be strong and unique

## 5. Tools / Concepts Used
- Password manager awareness
- Browser credential review
- Master password concept
- Password hygiene
