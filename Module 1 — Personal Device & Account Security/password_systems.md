# Password Systems

## 1. What I Learned
A password system is the mechanism used to verify identity and protect access to accounts or devices. Good password systems are not just about creating passwords — they also involve secure storage, verification, and protection against misuse.

Modern systems should not store actual passwords directly. Instead, they rely on techniques like hashing and salting.

## 2. Why It Matters
Weak password systems are one of the most common causes of account compromise. Password reuse, short passwords, and predictable patterns make accounts vulnerable to credential stuffing and unauthorized access.

This matters for both personal security and software engineering awareness.

## 3. Practical Exploration
I performed a personal password audit on important accounts and checked for:

- password reuse
- weak patterns
- dependency on personal information
- account risk if one credential gets leaked

I also improved one important account by making the password longer, stronger, and unique.

## 4. Key Takeaway
- A password system is more than just a password
- Length, uniqueness, and unpredictability matter most
- Password reuse is one of the biggest real-world security mistakes

## 5. Tools / Concepts Used
- Password audit
- Credential stuffing awareness
- Password strength evaluation
- Authentication basics
