# Wi-Fi Safety & Network Trust Basics

## 1. What I Learned
Wi-Fi networks represent different levels of trust. Connecting to a network means sending data through that environment, which may vary in safety depending on whether it is private, shared, or public.

## 2. Why It Matters
Using untrusted or public networks without awareness can expose data, increase risk, and weaken overall device security. Network choice should match the sensitivity of actions performed.

## 3. Practical Exploration
I reviewed saved Wi-Fi networks, removed unnecessary or old public connections, and evaluated my behavior while using public and private networks.

I also made small improvements like disabling auto-connect and being more selective with network usage.

## 4. Key Takeaway
- A network is a trust boundary
- Public Wi-Fi should be used cautiously
- Sensitive actions should be done on trusted networks

## 5. Tools / Concepts Used
- Network trust awareness
- Wi-Fi management
- Device connectivity settings
- Security hygiene
