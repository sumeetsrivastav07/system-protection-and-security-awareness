# DNS (Domain Name System)

## 1. What I Learned
DNS is the system that translates human-readable domain names into machine-usable IP addresses.

It allows users to access websites using names like `github.com` instead of remembering raw IP addresses.

## 2. Why It Matters
DNS is a foundational part of how the internet works. Without it, web access would be inconvenient and many browser/network behaviors would be harder to understand.

It also matters for security awareness because phishing often relies on users trusting domain names too casually.

## 3. Practical Exploration
I used `nslookup` to observe how a domain gets resolved into one or more IP addresses.

This helped me understand how internet name resolution works in practice before a browser reaches a site.

## 4. Key Takeaway
- DNS translates names into network destinations
- Domain awareness is important for both networking and security
- DNS is a core invisible system behind normal internet usage

## 5. Tools / Concepts Used
- `nslookup`
- Domain name resolution
- IP mapping
- DNS awareness
