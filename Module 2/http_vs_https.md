# HTTP vs HTTPS

## 1. What I Learned
HTTP is a protocol used for communication between a browser and a server, while HTTPS is the secure version that encrypts data during transmission.

HTTPS ensures that data is protected while being sent across the network.

## 2. Why It Matters
Using HTTPS is important when entering sensitive information like passwords, personal data, or financial details. It helps prevent data interception during communication.

However, HTTPS does not guarantee that a website is legitimate or trustworthy.

## 3. Practical Exploration
I observed different websites and checked whether they used HTTP or HTTPS.

I also explored browser indicators like the lock icon and understood how the browser signals secure and insecure connections.

## 4. Key Takeaway
- HTTPS secures communication, not trust
- The lock icon only indicates encryption
- Domain verification is still necessary

## 5. Tools / Concepts Used
- HTTP vs HTTPS
- Browser security indicators
- Encrypted communication
- Connection awareness
