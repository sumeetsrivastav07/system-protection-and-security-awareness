# IP Addresses

## 1. What I Learned
An IP address is a network identifier used to allow devices to communicate over local networks and the internet.

I learned the difference between private IP addresses (used inside local networks) and public IP addresses (used externally on the internet), along with the basic difference between static and dynamic IPs.

## 2. Why It Matters
IP addressing is one of the core foundations of internet communication. Without it, devices would not know where to send or receive data.

Understanding IPs helps make later networking topics like DNS, routers, ports, and traffic flow much clearer.

## 3. Practical Exploration
I checked:

- my device’s local/private IP using `ipconfig`
- my network’s public IP using a browser search

I observed that the two were different and understood how private and public addressing work in practice.

## 4. Key Takeaway
- IP addresses are how devices are identified on networks
- Private IP and public IP are not the same thing
- Dynamic and static addressing affect how network identity behaves over time
