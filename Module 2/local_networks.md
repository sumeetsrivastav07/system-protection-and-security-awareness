# Local Networks

## 1. What I Learned

A local network (LAN) connects devices within a limited area such as a home, hostel, office, or college network.

Devices on a local network commonly use private IP addresses, while the router acts as a gateway between the local network and external networks.

## 2. Why It Matters

Understanding local networks helps explain how devices communicate, how routers connect local networks to the internet, and how private IP addresses are used.

It is also useful for understanding local backend servers and network-based application development.

## 3. Practical Exploration

Used `ipconfig` on Windows to inspect:

- IPv4 Address
- Default Gateway

Tested connectivity to the local gateway using `ping`.

## 4. Key Takeaway

- Private IP addresses are used within local networks.
- A router commonly acts as the gateway to external networks.
- `localhost` refers to the local machine, while a private IP identifies the machine within the local network.
