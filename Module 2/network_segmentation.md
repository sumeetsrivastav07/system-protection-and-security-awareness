# Network Segmentation

## 1. What I Learned

Network segmentation separates a network into different logical areas and controls communication between them.

A common example is separating a private network from a guest network.

Segmentation helps limit unnecessary device-to-device communication and reduce the potential impact of a compromised device.

## 2. Why It Matters

Segmentation is an important security principle used in home networks, enterprise networks, cloud environments, and data centers.

It helps reduce the blast radius of security incidents by limiting which systems can communicate with each other.

## 3. Practical Exploration

Reviewed the concept of guest networks and network isolation.

Considered which personal devices actually need to communicate with each other.

Connected network segmentation with private IP addresses, routers, firewalls, and least-privilege principles.

## 4. Key Takeaway

- Not every device needs unrestricted network access.
- Segmentation limits unnecessary communication.
- Network isolation can reduce the impact of a compromised device.
