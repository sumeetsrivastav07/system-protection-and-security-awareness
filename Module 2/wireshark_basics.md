# Wireshark Basics

## 1. What I Learned

Wireshark is a network protocol analyzer used to capture and inspect network packets.

It can show details about network protocols, addresses, ports, packet sizes, and communication patterns.

## 2. Why It Matters

Wireshark provides practical visibility into network communication.

It helps connect concepts such as DNS, IP addresses, ports, TCP, TLS, and HTTP/HTTPS with real network traffic.

It is useful for network troubleshooting, security analysis, and understanding application communication.

## 3. Practical Exploration

Installed Wireshark and captured traffic from my own computer.

Used display filters such as:

- `dns`
- `tcp`
- `tls`

Inspected individual packets and observed protocol layers.

## 4. Key Takeaway

- Network communication is transmitted through packets.
- Wireshark can capture and inspect network traffic.
- HTTPS/TLS encrypts application content but does not necessarily hide all network metadata.
