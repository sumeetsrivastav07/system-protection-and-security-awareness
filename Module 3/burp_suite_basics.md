# Burp Suite Basics

## 1. What I Learned

Burp Suite is a web application testing platform used to inspect and test HTTP/HTTPS communication.

Its Proxy functionality allows authorized testers to inspect requests and responses between a browser and a web server.

## 2. Why It Matters

Burp Suite helps developers understand HTTP communication, cookies, sessions, authentication, and web application security testing.

## 3. Practical Exploration

Explored Burp Suite's Proxy tools and HTTP history.

Inspected a request and response in a controlled environment using an application I own or am authorized to test.

Focused on observation rather than modifying requests.

## 4. Key Takeaway

- A proxy can act as an intermediary between a browser and a server.
- HTTP history helps inspect web communication.
- Testing must be limited to authorized environments.

## 5. Tools / Concepts Used

- Burp Suite Community Edition
- Proxy
- HTTP history
- HTTP requests and responses
- HTTPS
- Cookies and sessions
