# Legal Security Labs

## 1. What I Learned

A security lab is a controlled environment for learning security concepts and practising authorized testing.

Examples include OWASP Juice Shop and PortSwigger Web Security Academy.

## 2. Why It Matters

Security labs provide a safe setting to understand web vulnerabilities, application behavior, and defensive techniques without testing unauthorized systems.

## 3. Practical Exploration

Reviewed the introductory learning material on PortSwigger Web Security Academy.

Explored its purpose as a platform for structured web security learning.

## 4. Key Takeaway

- Practise only on systems you own or are authorized to test.
- Controlled labs help develop practical security knowledge.
- Understanding prevention is as important as understanding vulnerabilities.
