# File Metadata Awareness

## 1. What I Learned

Metadata is information describing a file, such as its format, size, timestamps, author information, image dimensions, or GPS coordinates.

The available metadata depends on the file format and how the file was created or processed.

## 2. Why It Matters

Metadata can reveal information that is not immediately visible when viewing a file.

Understanding metadata helps with privacy protection, file analysis, digital forensics awareness, and responsible information sharing.

## 3. Practical Exploration

Inspected the Properties → Details section of a personally owned file on Windows.

Optionally used ExifTool to inspect metadata from a local photograph.

Checked whether GPS-related metadata was present without uploading private files to third-party services.

## 4. Key Takeaway

- Metadata is information about a file.
- Files may contain sensitive information beyond their visible content.
- Metadata can be absent, modified, or inaccurate.
