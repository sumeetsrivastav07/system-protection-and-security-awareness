# OSINT Fundamentals

## 1. What I Learned

OSINT stands for Open-Source Intelligence. It involves collecting and analyzing information from publicly available sources to answer a specific question.

Examples of sources include public websites, documentation, news articles, public announcements, and published file metadata.

## 2. Why It Matters

OSINT supports cybersecurity research, threat intelligence, journalism, and privacy awareness.

It also helps explain how publicly available information can create security risks when collected and combined.

## 3. Practical Exploration

Designed a hypothetical OSINT exercise around a fictional software project.

Identified potential public sources, including README files, documentation, release notes, and security policies.

Practised distinguishing documented evidence from assumptions.

## 4. Key Takeaway

- Define a clear research question before collecting information.
- Verify important findings against reliable sources.
- Public information should be handled responsibly and interpreted carefully.
