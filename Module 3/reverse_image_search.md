# Reverse Image Search

## 1. What I Learned

Reverse image search uses an image as the search input to find potentially related images and webpages.

Tools such as Google Lens and TinEye can help locate similar images and investigate where an image may have appeared online.

## 2. Why It Matters

Reverse image search supports image-source research, verification of public information, misinformation awareness, and responsible digital investigation.

## 3. Practical Exploration

Used a non-sensitive image to explore reverse image search.

Reviewed related images and webpages, then compared their source information and publication context.

## 4. Key Takeaway

- Similarity does not prove that two images are identical.
- Search results alone do not establish an image's authenticity or origin.
- Image search and file metadata provide different types of evidence.
